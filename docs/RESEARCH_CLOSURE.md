# 한국어 정책 문장의 사실·정정·내용 변화 연구 결산

2026년 10월 2일, 이번 개인 후속 연구 묶음의 실험과 공개 기록을 마감했습니다. 정책·기사·시장 데이터를 연결했던 개발에서 출발해, 한국어 문장의 사실과 상태를 구분하고, 조건의 의미 변화를 실행하고, 정책 변경 뒤 이미 저장된 판단을 갱신하는 문제로 확장했습니다. 마지막 문서·예외 실험에서는 **직접 판독 Qwen 33/48·Kanana 27/48, 전체 본문 그래프 실행 0/48·0/48**을 얻었습니다. 실패와 보류도 결과에 포함했습니다.

## 개발 기반에서 연구 질문으로

교수님 요구에 맞춰 만든 분석 기반을 서울경제 활용 구조에 맞춰 확장한 과거 개발 과정과, 이후 독립적으로 구성한 개인 NLP 실험을 구분합니다. [개발 회고](DEVELOPMENT_JOURNEY.md)와 [구현 지도](WORKSTREAMS.md)는 과거 구현 근거를, 각 연구 패키지는 AI 보조로 설계·구현·실행한 후속 실험의 조건과 결과를 보존합니다. 이 정리는 제3자의 기여나 권리 귀속을 대신 판단하지 않습니다.

연구의 출발점은 문장의 판독 결과를 보고서나 누적 지표에 넣기 전에 무엇을 믿을 수 있는지 확인하는 것이었습니다. 같은 숫자라도 기준과 후속 값의 역할이 다르고, 변경을 언급해도 실제 확정된 변경이 아닐 수 있습니다. 나중에는 문장 하나를 맞히는 것만으로 부족해져, 누구에게 적용되는 조건인지와 기존 판단이 언제 바뀌어야 하는지를 확인했습니다.

## 이번 연구가 보여주는 것

실험의 기여는 모든 정책을 자동으로 읽는 완성된 모델이라는 주장이 아닙니다. 같은 자료에서도 사실 추출, 정책 규칙 추출, 계산, 기존 판단 갱신이 서로 다르게 실패한다는 점을 실제 저장 결과로 추적했습니다. 단순 정확도 뒤에 가려지는 금액 오독, 선택적 보류가 핵심 과제를 모두 지우는 문제, 새로운 문서에서 다시 생기는 실패를 남겼습니다.

원문 후보와 사실 보정으로 개선된 이전 결과에는 제한 규칙의 기여가 큽니다. 마지막 실험에서도 구조화 결합의 우월성은 입증하지 못했습니다. 이 결과를 언어모델 단독의 이해력 향상으로 포장하지 않고, 어디를 코드가 계산했고 어디를 모델이 읽었는지 구분하는 평가와 재현 구조를 남겼습니다.

## 마감 범위

이번 묶음에 포함한 코드·자료·응답·실패·동결·재현 결과와 홈페이지 시각화를 정리했습니다. 마지막 실험은 6개 문서, 48개 작성 사례, 120개 새 저장 응답입니다. 공식 원문 전체와 원시 응답, 고객의 비공개 자료는 재배포하지 않습니다. 원래 개발 이력을 보존하면서 개인 후속 연구를 별도로 기록했습니다.

독립 사람 판독, 전체 사업의 자격 판단, 실제 검토 시간 절감, 다양한 기관·주제에 대한 일반화는 입증하지 않았습니다. 마지막 사례 48행의 사람 검수 양식은 준비했지만 완료 0건이며 AI 검토를 사람 판독으로 대체하지 않았습니다. 이는 이번 실행을 계속 열어 두는 예정 작업 목록이 아니라 **현재 결과를 해석할 때 지켜야 하는 경계**입니다.
