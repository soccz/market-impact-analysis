# 개발 기여와 구현 이력

이 문서는 soccz가 담당한 개발 업무를 공개 코드 및 실제 커밋과 연결하기 위해 2026년 9월에 정리했습니다. 현재의 회고를 과거에 작성한 기록으로 표시하지 않습니다.

전체 과정을 시간순으로 읽으려면 **[정책 뉴스 분석 — 문제를 다시 정의하며 이어 온 개발 과정](DEVELOPMENT_JOURNEY.md)**에서 시작할 수 있습니다. 3–8월의 질문·실험·수정과 후속 적용을 연결하고, 공개 커밋과 비공개 자료에 근거한 회고를 구분했습니다. 이 문서는 모듈과 함수별 구현 근거를 찾아가는 색인입니다.

추가 진입점: [업무별 입력·구현·산출물 전체 지도](WORKSTREAMS.md) · [합의 코드 실제 실행과 네 가지 심층 사례](ENGINEERING_CASES.md). 초기 공개 구현의 판독·재검토 큐, 배치 추론 처리와 후속 운영·검증 작업까지 확장해 설명했습니다.

## 개발 기여

정책 이벤트, 뉴스 텍스트, 시장 데이터를 정리하고 비교하는 소프트웨어를 구현했습니다. 주요 업무는 정책별 입력 구성, 뉴스의 정책 맥락 처리, 일별 집계, 모델·포트폴리오 비교 자료와 시각화용 결과 생성입니다.

교수님 피드백을 반영한 연구용 기반과 서울경제 요구에 맞춘 활용 작업은 연결돼 있습니다. 다만 공개 저장소의 초기 구현과 이후 납품 구현의 범위는 같지 않습니다. 이 문서는 공개된 부분에서 확인할 수 있는 구현을 구체적으로 안내합니다.

### 함수와 산출물을 따라 읽는 개발 맵

직접 실행하며 읽으려면 [작은 입력으로 공개 구현 읽기](REPRODUCIBLE_EXAMPLES.md)에서 시작할 수 있습니다. 합성 기사 네 건으로 관련성과 입장을 구분한 이유, 규칙의 표현 변형 한계를 확인합니다.

아래 표는 파일의 이름만 나열하지 않고 실제 입력과 처리, 출력의 의미를 대응시킨 기록입니다. 설명 기준은 공개 코드의 `5193cbb` 시점이며 이번 문서 개편에서 과거 분석 코드를 변경하지 않았습니다.

### 설계 판단과 남은 문제

- **정책 관련성과 입장을 분리:** 종목명이 등장했다는 사실만으로 정책 관련성을 승인하지 않고, 정책어 적중과 구체성 보조 정보를 나눴습니다. 짧은 본문과 표현 변형에 대한 누락 문제는 남습니다.
- **가설 생성을 공통화:** 정책 유형별 템플릿을 만들었습니다. 초기 파일에는 개별 정책의 재분류와 검토 표시도 있으므로 완전히 예외 없는 규칙이라고 주장하지 않습니다.
- **경로·신규성의 이중 반영 검토:** 같은 의미를 담은 가중치를 반복 곱하지 않도록 초기 설계의 요소를 구별했습니다. 효과의 크기는 별도 제거 실험으로 측정해야 합니다.
- **중간 집계를 보존:** 지지/반박과 기사 수를 따로 남겼습니다. 공개 일별 코드의 `diffusion = 1 - max_provider_share`는 매체 분포이며 독립적인 정보 출처 수는 아닙니다. 한 매체만 있는 날은 이 가중값이 0이 되는 특성이 있습니다.
- **평가의 출처 구별:** sanity 사례, 개발셋 합의 라벨, 사람의 독립 판독, AI 생성·보조 라벨은 역할이 다릅니다. 초기 문서의 모든 지표를 독립 사람 평가의 성능으로 읽을 수 없습니다.

이 구분은 PTEI 초기 설계와 이후 시장영향 점수, 교수님용 조건부 방향 비교, 서울경제용 누적 흐름 분석을 하나의 지표로 합쳐 설명하지 않기 위한 기준이기도 합니다.

## 연구 기반과 목적별 확장

제가 구현한 정책·기사·시장 데이터 연결 및 NLP 처리 기반을 활용하되, 교수님 피드백을 반영한 연구용과 서울경제 활용용은 분석 질문에 맞춰 다르게 구성했습니다. 아래는 방법론의 차이를 설명한 것으로 납품 설정표를 복제한 것이 아닙니다.

| 축 | 교수님 피드백을 반영한 연구용 | 서울경제 기획취재용 확장 |
|---|---|---|
| 질문 | 조건에 맞는 뉴스와 이후 수익률의 방향 비교 | 정책별 누적 뉴스·시장 흐름의 동행 |
| 처리 | 뉴스 날짜와 거래일 정렬, 시점 간 수익률과 부호 비교 | 일별 뉴스 집계·누적, 시장 기준 대비 수익률 흐름 구성 |
| 결과 단위 | 모델·포트폴리오·기간별, 정책별 동일가중 집계 | 정책별 비교 시계열·그래프·시각화 입력·보고서 |
| 해석 조건 | 필터에 따른 조건부 표본, 모델별 커버리지 | 누적 시계열의 성질, 탐색적 설정 선택의 영향 |

날짜 정렬·포함 표본·집계와 출력 규격을 구현한 개발 기여와, 그 결과로 강한 통계적 결론을 내릴 수 있는지는 구별합니다. 이후 연구용·납품용 전체 구현을 이 초기 공개 코드로 재현할 수 있다고 표시하지 않습니다.

- [개인 홈페이지의 개발 사례](https://soccz.github.io/projects/market-impact-v2/): 어떤 문제를 발견했고 어떤 설계 판단을 했는지 설명합니다.
- [서울경제 「뉴스의 힘」](https://en.sedaily.com/atlas/news-power#e1): 분석 데이터가 활용된 공개 콘텐츠입니다. 보도·편집, 웹 콘텐츠 구현 및 별도 분석은 해당 수행 주체의 기여입니다.

교수님·연구실의 연구 지도와 서울경제의 기획취재 요구를 함께 표시합니다. 범용 사전학습 모델 자체의 개발, 기사 작성, 공개 사이트 전체의 제작을 본인의 구현 범위로 포함하지 않습니다.

## 개인 후속 연구

2026년 9월 회고에서 새로 구체화한 질문은 사전 예상과 실제 발표의 차이, 기업별 정책 노출 경로, 반복 보도와 새로운 사실의 구분입니다. 별도 로컬 프로토타입에서 합성 입력으로 정보 변경 추적의 최소 동작을 점검했습니다. 해당 코드·세부 실험 설계는 이 공개 저장소에 포함하지 않았습니다. 실제 뉴스 추출·시장 데이터 평가, 학술적 차별성 검증은 남아 있습니다. 기존 계약의 납품 성과로 소급해 표시하지 않습니다. 공개 개요는 홈페이지의 [개인 후속 연구](https://soccz.github.io/projects/market-impact-v2/#next)에 있습니다.

추가로 정정의 파급 범위, 원문 의존성, 다음 확인할 자료를 연구 질문으로 구체화했습니다. [연구 설계와 공개 합성 예제](RESEARCH_AGENDA.md), [시각 연구 노트](https://soccz.github.io/projects/market-impact-research/)에서 제안·설명용 구현·미실행 평가를 구별해 확인할 수 있습니다.

9월 30일에는 별도의 **한국어 정책 문장 NLP 실험**을 실행했습니다. 공개 KLUE 자료로 세 초기값의 모델 학습을 비교하고, 합성 표현 변화에 대한 실패를 진단한 뒤 정정·변경 관계와 금액 근거 위치를 추출하는 실험으로 발전시켰습니다. 이 독립 후속 실험의 코드·합성 입력·원시 예측은 새 `research/policy_revisions/`에 공개했습니다. 위 비공개 변경 추적 엔진이나 고객 납품 구현과는 별도입니다. [전체 결과와 한계](KOREAN_POLICY_NLP.md)에 개선된 점과 실제 문서에서 남은 오판, 사람 판독 미완료를 함께 기록합니다.
