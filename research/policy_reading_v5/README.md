# 질문 대상에 따라 근거와 금액을 연결하는 정책 판독 v5

soccz의 개인 후속 연구 · 2026년 10월 1일. 설계·구현·합성 자료·분석에 AI 지원을 사용했습니다. 고객 원자료와 납품 구현은 사용하지 않았습니다. 독립 사람 판독 완료는 **0건**입니다.

## v4의 실패에서 출발한 질문

금액 표기를 `0원`으로 통일하자 단위 변화에는 안정됐지만 다른 사업의 금액이 대상에 연결됐습니다. v5는 **같은 본문에서 질문하는 사업만 바꿨을 때 금액 역할과 근거도 바뀌는가?**를 직접 검사합니다. 이전의 단일 질문 정답률만으로 확인하기 어려웠던 대상 의존성을 평가합니다.

본문 하나에는 두 사업의 기준·후속 금액, 관계, 진행 상태를 넣습니다. 같은 본문으로 질문 두 개를 만들고, 서로 다른 정답 축·금액 역할·근거를 부여합니다. 두 행은 항상 같은 분할에 둡니다. 주지표는 **두 질문의 관계·상태·금액 역할 전체를 모두 맞힌 본문 비율**입니다. 한 질문만 맞히는 것, 답만 바뀌는 것과 구분합니다. 근거 문자 F1은 별도 지표이며 공동 일치의 구성 요소는 아닙니다.

## 개입과 대조군

모든 조건에서 아라비아 숫자 원화 금액을 `0원`으로 통일하고 실제 값·위치를 별도로 보존합니다. 대상 표시는 입력 `query`와 정확히 같은 문자열을 본문에서 찾아 `지정사업`으로 치환하고 질문도 같은 이름으로 통일합니다. **규칙에 의한 정확 문자열 치환**이며 학습한 개체 연결기나 사건 경계 모델이 아닙니다. 정답 사업 목록·금액 역할·근거 위치는 입력 처리에 사용하지 않습니다. 원문은 별도로 유지하고 모델 출력만 원문 위치로 복원합니다.

| 조건 | 가중치 | 질문·본문 처리 |
|---|---|---|
| 이전 모델 | v4 문맥 보강 모델 3개 재사용 | 질문과 사업명 유지 |
| 이전 모델 + 대상 표시 | 위와 같은 3개 | 정확한 대상명 치환 |
| 질문 쌍 학습 | 새 학습 3회 | 질문과 사업명 유지 |
| 질문 쌍 + 대상 표시 | 새 학습 3회 | 정확한 대상명 치환 |
| 질문 가림 대조 | 새 학습 3회 | 질문만 상수로 가리고 본문 유지 |

질문 가림은 동일 입력에 서로 다른 정답을 요구하는 **의도적인 음성 대조군**입니다. 두 질문 동시 정답은 구조적으로 불가능합니다. 그 결과 0%를 새로운 발견이나 우수성의 크기로 해석하지 않습니다. 대상 표시도 위치 표시와 어휘 정규화가 함께 바뀌므로 두 효과를 분리한 실험이 아닙니다.

새 학습 9회: 동일 KLUE-RoBERTa-base 상위 2개 층과 출력층, 동일 손실, 초기값 17·42·2026, 10 epoch, 300회 갱신 시도, 유효 batch 32, encoder 2e-5·출력층 1e-3. 마지막 체크포인트를 사용합니다. fp16 overflow로 생략된 갱신은 로그에 남깁니다. 모든 v5 추론은 고정 길이 192·fp32이며 무음 절단을 금지합니다. 이전 v4 기록의 길이 128과 달라 **v4의 기존 점수와 직접적인 한 요소 효과로 비교하지 않습니다.**

## 자료를 어떻게 나눴는가

- 학습 960행 = 480본문 × 2질문. 검증 192행 = 96본문 × 2질문. 기본 평가 384행 = 192본문 × 2질문.
- 관계 4종 × 상태 6종의 24개 조합을 학습합니다. 이번에는 미관측 관계·상태 조합 일반화를 주장하지 않습니다. 두 사업의 조합 짝, 사업명, 관계·상태 표현 family는 평가에서 바뀝니다.
- 기본 문장 배치는 사업별로 설명이 모여 있습니다. **교차 배치**는 두 사업의 금액을 먼저 쓰고 상태·사유를 반대 순서로 씁니다. **지시어 배치**는 이름을 처음 열거한 뒤 ‘앞서/뒤에 언급한 사업’으로 지칭합니다. 두 배치는 학습에 없지만 같은 평가 사건을 다시 쓴 것입니다.
- **순서 반전**, **원 단위 표기**도 같은 평가 사건의 대응 변형입니다. 독립적인 새 사건 수에 더하지 않습니다.
- **대상 미등장**은 같은 192본문에 없는 사업을 질문합니다. 금액은 모두 기타, 축은 불명으로 두며 강제 출력과 검증에서 정한 보류의 동작을 확인합니다. ‘불명’ 라벨과 출력 보류는 다릅니다.

[자료 생성 규칙](build_probe.py), [규모·균형](data/design.json), [실제 토큰 길이·정규화 표현 수](input_audit.json)를 공개합니다. 숫자·이름을 바꾼 개수를 자연 언어의 독립 사례 수로 세지 않습니다. 새로운 사업·표현이지만 같은 작성자의 유한 문법이며, 기본 4개 표현 family만으로 언어 모집단의 신뢰구간을 추정하지 않습니다. **새로 만든 합성 진단이지 독립 실제 문서 시험이 아닙니다.**

## 검증과 보류

[설계](protocol.json)와 [27개 입력 해시](freeze.json)는 이번 학습·추론 전에 로컬에서 고정했습니다. 외부 사전등록은 아닙니다. 결과에 따라 자료·학습률·epoch를 다시 바꾸지 않습니다. 이전 v3·v4 파일도 수정하지 않습니다.

검증에서 공동 오류 5% 이하, 최소 20개 응답을 만족하는 최대 답변율 문턱을 선택합니다. 만족하는 문턱이 없으면 모두 보류합니다. 실제 입력에 정답을 넣는 규칙은 없습니다. 이 기준이 새로운 문장 배치·실제 문서의 낮은 오류를 보장하지 않습니다. 모든 조건·초기값·유형별 응답률을 [summary.json](summary.json)에 보존합니다.

입력 검사로 정답을 바꿔도 토큰이 동일한지, 두 질문의 본문이 같은지, 분할에 본문이 겹치지 않는지, 원문 위치·값이 복원되는지 확인합니다. 결과 검사는 원확률·결정·지표·쌍별 동시 정답·유형별 보류를 별도로 재계산합니다. **이 검사는 언어적 정답 자체에 대한 사람 검증을 대신하지 않습니다.**

## 결과 이후 추가한 문장 선별 비교

주 실험의 새 학습에서 두 질문 동시 정답을 얻지 못한 뒤, **정확한 질문 사업명이 들어 있는 문장만 기존 모델에 주는 기준선**을 추가했습니다. 이 시점과 설계를 [별도 프로토콜](routing_protocol.json)·[잠금](routing_freeze.json)으로 남겼습니다. 주 실험의 코드·자료·학습 설정과 9회 결과는 바꾸지 않았고 학습도 추가하지 않았습니다.

선별된 문장에 금액이 하나라도 있을 때만 모델에 입력하고, 그렇지 않으면 명시적으로 보류합니다. 제외된 금액은 규칙으로 기타 처리합니다. 근거 구절을 원문으로 복원할 때 잘라낸 문장까지 근거에 포함하지 않도록 끊어서 매핑합니다. 정확 문자열 규칙이 만든 결과와 신경망 예측을 구분합니다. 단순한 전처리 비교이며 학습된 문장 검색기·담화 해석기가 아닙니다.

전체 본문 기준 공동 일치에서는 보류를 정답으로 세지 않고, 선별 가능 비율과 보류 문턱을 따로 보고합니다. [선별 결과](routing_summary.json), [원예측](routing_results/), [독립 지표 검증](routing_verification.json)을 공개합니다. 공개 재학습 도구는 이 기존 모델의 선별 예측도 그대로 재사용하며, 가중치가 있어야 새 추론을 할 수 있습니다.

## 해석의 경계와 다음 질문

사업명의 정확 문자열을 찾는 처리는 별칭·줄임말을 해결하지 못하고 부분 문자열을 잘못 찾을 수 있습니다. 질의가 금액과 겹치는 입력은 지원하지 않습니다. 원화 파서의 지원 범위도 그대로 제한됩니다. 값이 가려진 인코더는 수치의 동치·방향을 직접 학습하지 않았습니다. 관계·상태 라벨은 문서에 쓰인 설명이며 정책의 실제 시행이나 사실성을 외부 검증한 결과가 아닙니다.

이번 실험은 지시어·교차 배치의 어려움을 측정하지만, 화자·인용·부정 범위의 해소나 실제 문서 버전 연결까지 구현한 것은 아닙니다. 실제 공고 수집·사건 분리와 독립 2인 판독이 남아 있습니다. 새 공식 문서를 추가하지 않았으며 v4의 공식 12사례 점수를 새 v5 모델의 성능으로 옮겨 적지 않습니다.

사업 중심 관계 표현은 [Matching the Blanks (ACL 2019)](https://aclanthology.org/P19-1279/), 입력 변화별 동작 검사는 [CheckList (ACL 2020)](https://aclanthology.org/2020.acl-main.442/)를 참고했습니다. 해당 논문의 모델·실험을 재현하거나 기법 자체의 신규성을 주장하지 않습니다. 기여 후보는 한국어 정책 문장에서 **대상 질문·근거·금액·보류를 함께 반증할 수 있는 기록과 평가**입니다.
