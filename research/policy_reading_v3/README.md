# 정책 문장의 관계·상태·근거 분리 실험 v3

개인 후속 연구. 이전 개발 경험에서 남은 “내용이 바뀐 것과, 바뀌었다는 주장의 상태를 어떻게 구별하는가?”를 좁은 판독 과제로 만들었습니다. 고객 원자료나 납품 코드를 사용하지 않았습니다. 코드·합성 문법·임시 판독·글 작성에는 AI의 지원을 받았습니다.

## 이번에 검증하는 것

입력은 사람이 지정한 대상 `query`와 짧은 구절 `text`입니다. 출력은 아래 네 가지입니다.

1. **관계:** 오기 정정 / 실질 정책 변경 / 같은 금액의 재표현 / 관계 불명.
2. **상태:** 확정 서술 / 계획 / 검토·미확정 / 부인 / 가정 / 상태 불명.
3. **금액 역할:** 기준 안내 / 후속·예정 안내 / 다른 금액. 원문 위치와 원 단위 값도 남깁니다.
4. **사유 구절:** 관계와 상태를 뒷받침하는 원문 범위. 근거 학습 조건에서만 추가 손실을 줍니다.

`policy_change + denied`는 **변경이 있었다는 주장을 부인했다**는 판독입니다. 실제 정책 변경으로 집계하면 안 됩니다. `asserted`도 문서의 서술 방식이지, 시행 여부·진실성의 독립 확인이 아닙니다. ‘미확정’과 ‘발생하지 않음’을 구분합니다. 대상 자동 검색, 문서 전체 판독, 실제 사건의 모든 버전 연결까지 구현한 시스템은 아닙니다.

## 데이터와 고정한 비교

| 분할 | 행 | 숫자·대상명을 가린 표현 | 표현 묶음 | 학습에 없던 관계×상태 조합 |
|---|---:|---:|---:|---:|
| 학습 | 960 | 120 | 6 | 0 |
| 검증 | 160 | 40 | 2 | 0 |
| 평가 | 576 | 96 | 4 | 96행·4조합 |

평가의 480행은 학습에서 본 관계·상태 조합을 **새 표현**으로 쓴 것이고, 96행은 새 표현과 새 조합을 동시에 적용합니다. 학습에서 제외한 조합은 정정×계획, 정책 변경×부인, 재표현×가정, 관계 불명×검토·미확정입니다. 각 관계와 각 상태 자체는 학습에서 관측됩니다.

숫자 반복을 독립 언어 사례로 세지 않습니다. 같은 작성자가 만든 유한한 명사구·상태 구문을 조합하므로 어휘 단서로 해결할 수 있습니다. 사실·정정·변경의 자연어 일반화나 정책 전문가 수준을 입증하는 정답집이 아닙니다.

| 조건 | 학습하는 문장 출력 | 공통 금액 역할 | 추가 근거 손실 |
|---|---|---|---|
| `flat` | 관계×상태 24가지 중 하나 | 있음 | 없음 |
| `factor` | 관계 4개와 상태 6개를 각각 예측 | 있음 | 없음 |
| `evidence` | 관계와 상태 각각 예측 | 있음 | 관계·상태 근거 토큰 |

세 조건은 동일한 KLUE-RoBERTa-base, 초기값 17·42·2026, 학습 순서, 3 epoch, 유효 batch 32, 학습률 2e-5를 사용합니다. **전체 층 추가 학습이 아니라 상위 2개 encoder 층과 출력층만 학습합니다.** 최초 전체 층 학습은 다른 프로세스의 GPU 사용으로 첫 forward에서 실패했습니다. 원 계획·코드는 [최초 잠금](freeze.json)에 보존하고, 결과를 보기 전의 자원 변경을 [수정 계획](partial_protocol.json)과 [수정 잠금](partial_freeze.json)에 남겼습니다. 모든 유지된 신경망 실험에 같은 조건을 적용합니다.

24분류는 학습에서 제외한 출력 클래스에 정답 학습 신호가 없습니다. 따라서 이를 유일한 비교 대상으로 삼지 않고, **같은 24분류 확률을 관계·상태별로 합친 후 각각 선택하는 `flat:marginal`**도 비교합니다. 문자 n-gram 독립 분류기와 근처 문맥 금액 역할 분류기도 다시 학습합니다. 목적 함수의 합산 크기와 활성 출력 매개변수 수는 다릅니다. 모델 구조의 신규성이나 단일 요소의 인과 효과를 주장하지 않습니다.

## 수치 제약·반례·보류

- **수치 제약:** 모델이 연결한 기준·후속 금액이 각각 하나이고 환산값이 다르면 ‘같은 금액’ 확률만 제거합니다. 정답 역할을 넣지 않고, 숫자가 다르다는 이유로 ‘정정’이라고 단정하지 않습니다. 텍스트가 두 값의 동치를 부인하는 경우에는 이 제약도 부적절할 수 있습니다.

  24분류의 `numeric`은 관계·상태 주변확률에 제약을 적용해 축별로 선택하므로, 수치 제약만의 차이를 볼 때는 `flat:marginal`과 비교해야 합니다. 원래 24개 클래스의 공동 argmax와 비교하면 선택 방식도 함께 바뀝니다.

- **방해 문장:** 다른 사업의 정정 부인과 두 금액을 추가합니다. 대상 판독이 유지되는지 확인합니다. 복잡한 임의 위치·다중 사건 전체를 검증한 것은 아닙니다.
- **단위 변환:** 원문 금액을 동일한 원 단위로 적습니다. 표면 단위에 기대는지 확인합니다.
- **근거 제거:** 정답 근거 구절을 지운 뒤 출력과 확신의 변화를 봅니다. 정답을 아는 oracle 진단이며, 제거 후 정확도나 근거의 인과적 충분성을 증명하지 않습니다.
- **보류:** 검증 160행에서 공동 오류 ≤5%, 응답 ≥20을 만족하는 최대 응답 문턱을 고정합니다. 조건이 없으면 전부 보류합니다. 평가·공식 자료로 문턱을 고르지 않습니다. 유형별 답변율과 오답을 같이 공개합니다.

공동 일치는 관계·상태와 **탐지된 모든 금액의 역할·위치·값**이 모두 맞는 비율입니다. 숫자가 없는 공식 구절은 금액 역할이 공집합으로 맞을 수 있으므로 합성 금액 과제와 합산하지 않습니다. 근거 F1은 공백을 제외한 문자 위치와 종류의 micro F1입니다. 근거를 출력하지 않는 조건의 0은 학습 비교의 별도 과제 실패율로 해석하지 않습니다.

## 공식 출처와 사람 판독

[12개 공식 구절](data/official.jsonl)은 5개 기존 출처와 7개 새로 확인한 출처입니다. 짧은 원문 인용·출처·발표일·본문 해시·인용 위치를 함께 남겼습니다. 정부가 무엇을 설명했는지 판독하는 사례이며, 정부 주장 자체의 독립 진위 판정이 아닙니다. 전체 웹 수집이나 모집단 무작위 표본이 아니며 재표현·가정 등의 유형은 없습니다. 하나의 공고 안에 적힌 전후 값과 실제 두 버전의 공고를 수집한 것은 다릅니다. 후자는 미완료입니다.

원문 전체 캐시와 모델 가중치는 로컬에 보존합니다. 공개 묶음에는 짧은 인용과 결과만 포함합니다. 새 구절은 공공누리 제1유형 텍스트 표시를 확인했고, 제4유형이 표시된 후보는 이 묶음에서 제외했습니다. 이 기록은 계약 검토나 포괄적인 법적 권리 확인을 대신하지 않습니다.

[독립 판독 안내](annotation/GUIDE.md)와 판독자별 빈 CSV 108행을 준비했습니다. 사람 판독 **완료 0건**이며 동의율·κ가 아직 없습니다. 임시 정답과 원예측을 보기 전에 판독할 수 있도록 별도 키는 공개하지 않습니다. ‘인상한다’의 확정·계획 구분 등 모호한 공식 사례를 이견으로 보존해야 합니다.

## 자료 보강의 2×2 사후 진단

첫 조건 9회, 학습 조건 추가 비교 9회 뒤에 원 단위·방해 문장에서의 실패를 확인했습니다. 최초 학습에서 이전 금액이 전부 만원 표기였다는 상관을 찾아, 단위만·대상 문맥만·둘 다 보강한 3조건을 세 초기값으로 추가했습니다. **총 27회 신경망 학습**이며, 학습 자료의 행 수·대상 라벨·모델·갱신 시도 예산을 맞췄습니다. 자세한 결과와 역효과는 [2×2 진단](AUGMENTATION.md), [모든 seed 원시 예측](results_augmentation/)에 있습니다.

보강은 이미 관측한 반례를 이용한 사후 연구입니다. 평가를 새 블라인드 자료로 부르지 않습니다. 제외한 관계·상태 조합은 대상 정답 기준이며 다른 사업 문구에는 나타날 수 있습니다. 다른 사업명의 어휘 단서까지 제거한 자연 문장 일반화는 미검증입니다. 세 근거 토큰 라벨은 상호 배타적이라 하나의 토큰에 관계와 상태 근거가 겹치는 실제 표현도 충분히 나타내지 못합니다.

같은 fp16 설정과 입력 노출을 사용했으나 overflow로 실행별 1–2회의 실제 갱신이 생략됐습니다. `training.json`에 attempted step과 skipped 여부를 보존합니다. 원 로그의 비표준 JSON `Infinity`는 원문을 로컬에 보존하고 공개 로그에서는 문자열로 표시합니다. 손실·예측·가중치를 바꾼 것이 아닙니다.

## 실행·재현

Python 3.12, torch 2.2.2, transformers 4.39.3, scikit-learn 1.7.2를 사용했습니다. CUDA 학습은 fp16, 예측은 fp32 고정 padding 128입니다. 모든 입력이 잘리지 않는 것을 확인했습니다. 학습 체크포인트의 SHA-256과 실행 환경은 각 `training.json`에 있습니다. 공개 모델 준비·캐시 경로는 `--model`로 지정합니다.

원본 결과를 덮어쓰지 않으므로, 새 빈 디렉터리에 코드·데이터·잠금을 복사한 뒤 실행합니다. `reproduce.py`가 이 작업을 수행합니다. 전체 학습 결과의 비트 단위 재현은 하드웨어·라이브러리에 따라 달라질 수 있습니다. 공개 묶음만으로 기존 가중치를 즉시 불러올 수는 없습니다.

```bash
python reproduce.py --regime fit --work /tmp/policy-reading-v3-reproduction --model /path/to/klue-roberta-base
# 다른 새 폴더에서 --regime initial / units / scope / both도 각각 재현 가능
# 위 명령은 새 폴더 안에서 학습·평가·검증을 차례로 실행합니다.

# 공개된 기존 결과만 검사할 때는 현재 폴더에서:
python verify.py
python verify.py --fit
python verify.py --augmentation units
python verify.py --augmentation scope
python verify.py --augmentation both
python annotation.py compare annotation/reviewer_a.csv annotation/reviewer_b.csv --out annotation/agreement.json
```

`initial`·`fit` 재현은 각각 별도 작업 폴더에서 기준선과 신경망 9개를 학습합니다. 보강 재현은 선택한 자료 조건의 신경망 3개를 학습합니다. 이미 있는 폴더를 덮어쓰지 않습니다. 숫자 검증은 언어적 임시 정답의 타당성을 증명하지 않습니다. v1/v2는 과제와 라벨이 다르므로 서로의 정확도를 연결해 연속 성능 상승 그래프로 표시하지 않습니다.

그림은 `report.py`와 `report_augmentation.py`가 원시 결과에서 생성합니다. 두 보고서는 전체 조건의 결과가 필요하며, Noto Sans CJK 글꼴과 Matplotlib을 사용합니다. PDF는 한글의 표시·검색을 보존하기 위해 Cairo 백엔드(`cairocffi`와 시스템 Cairo)를 사용합니다.

참고: [KLUE](https://github.com/KLUE-benchmark/KLUE), [KLUE-RoBERTa](https://huggingface.co/klue/roberta-base), [CheckList](https://aclanthology.org/2020.acl-main.442/), [EQUATE](https://aclanthology.org/K19-1033/). 전수 문헌 검토나 선행 연구 대비 신규성 검증은 아직 하지 않았습니다.
