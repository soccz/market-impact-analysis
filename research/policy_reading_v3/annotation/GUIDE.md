# 독립 판독 준비 — 아직 사람 평가를 수행하지 않았습니다

이 자료는 금액의 차이, 문서 오류의 수정, 정책 변경, 확정 상태를 구분하기 위한 **개인 연구의 검토 양식**입니다. 판독자는 108개 항목을 각각 읽습니다(서로 다른 합성 표현 96개 + 선정 공식 구절 12개). 동일 구절이 다른 숫자로 반복되는 나머지 행은 별개의 독립 언어 사례로 늘리지 않았습니다.

## 진행

1. 담당자는 각 판독자에게 이 안내와 `reviewer_a.csv` 또는 `reviewer_b.csv`만 전달합니다. 저장소의 정답·예측·생성기와 비공개 키를 먼저 보지 않도록 합니다. 공개 저장소 접근을 기술적으로 차단한 블라인드 실험은 아닙니다. 이미 결과를 본 판독자는 이를 기록합니다.
2. 서로 상의하기 전에 독립적으로 작성합니다. `query`가 가리키는 사건을 `text` 범위에서 읽습니다. `url`은 출처 확인용이며, 원문 전체를 읽어 추가한 정보는 `notes`에 구분합니다. 날짜는 출처의 발표일이지 시행일이 아닙니다.
3. 관계와 상태를 따로 선택하고 원문 근거를 JSON 문자열 배열로 적습니다. 예: `["협의 중"]`. 근거가 없으면 `[]`로 적고, 모호성·대안 해석을 남깁니다. 빈 칸은 미판독이며 `unspecified`와 다릅니다.
4. 두 표를 `annotation.py compare`로 비교합니다. 일치율·κ는 둘 다 완료한 관계·상태에만 계산됩니다. 한 유형만 있어 κ가 정의되지 않으면 `null`입니다. 도구는 이견을 자동 정답으로 바꾸지 않습니다.
5. 제3자의 조정 또는 두 판독자의 근거 토론을 별도 기록합니다. 최초 라벨을 보존하고, 사건별 문서 버전의 연결과 시행 여부는 추가 자료로 확인합니다. 시간 비용·판독 경력·AI 사용 여부도 기록해야 합니다.

## 관계

| 값 | 문장에서 논의하는 사건 |
|---|---|
| `correction` | 잘못 기재·계산한 내용의 수정 |
| `policy_change` | 지원 규모·정책 범위 자체의 실질 변경 |
| `restatement` | 같은 금액을 단위만 달리 표현 |
| `unspecified` | 위 관계를 결정할 이유가 부족함 |

“인상했다는 것은 사실이 아니다”는 `policy_change` + `denied`입니다. **변경이 실제 발생했다는 뜻이 아닙니다.** 문서의 제목이 ‘정정’이어도 지급 기준 자체를 개편했다면 그 이유를 따라 판독합니다. 두 금액이 다르다는 사실만으로 정정·변경을 고르지 않습니다.

## 상태

| 값 | 읽는 범위 |
|---|---|
| `asserted` | 문서가 결정·이행을 확정적으로 서술함; 현실의 진실을 독립 검증한 뜻이 아님 |
| `planned` | 장래 계획·예정·의향 |
| `under_review` | 검토·협의 중 또는 명시적인 미확정; 미확정만으로 검토 진행을 추정하지 않음 |
| `denied` | 해당 사건의 발생·결정 등을 명시적으로 부인 |
| `hypothetical` | 가정·조건부 시나리오 |
| `unspecified` | 상태 근거가 없음 |

“인상한다”처럼 발표 결정과 향후 실행이 혼재할 수 있는 표현은 모호성을 반드시 남깁니다. 합성 문법에 맞춰 실제 구절의 애매함을 지우지 않습니다. ‘건강생활유지비’와 ‘자립수당’은 이러한 이견 가능성이 있는 선정 사례입니다.

## 금액과 근거

- `before_quotes_json`: 기준·이전 안내의 금액.
- `after_quotes_json`: 후속·수정·예정 안내의 금액. 실제 시행액으로 단정하지 않습니다.
- 다른 사업의 금액, 증감액, 총액과 다른 기준의 값은 연결하지 않습니다. 단순 숫자 표기가 없는 경우 `[]`입니다.
- 관계 사유와 상태 사유의 원문 구절을 별도로 표시합니다. 중첩을 허용하되 이유를 기록합니다.
- 이 모델은 원화 금액만 탐지합니다. 날짜·인원·퍼센트 등으로 과제가 확대되는 사례는 별도 태그로 제안할 수 있습니다.

## 실행

```bash
python annotation.py compare annotation/reviewer_a.csv annotation/reviewer_b.csv --out annotation/agreement.json
```

배포된 빈 표의 실행 결과는 **`pending`, 완료 0건**이어야 합니다. 이 코드를 실행한 것을 사람 판독 완료로 기록하지 않습니다.
