# 한국어 정책 조건을 원문에서 읽고 실행하기

soccz 개인 NLP 연구 · 2026-10-01 · AI 지원 조사·구현·잠정 판독.

이전 [수동 조건 연구](../policy_semantic_diff/)에서 만든 질문을 **전체 공고 → 자동 조건 추출 → 근거 위치 → 조건 실행 → 버전 비교**로 연결했습니다. 교수님 연구 요구를 반영한 정책 뉴스 개발, 서울경제 활용을 위한 후속 개발, 개인 NLP 실험 v1–v5를 거쳐 이어진 후속 연구입니다. 이번 작업은 공개 공고와 공개 모델만 사용하며 기존 납품 구현·원자료를 포함하지 않습니다.

## 실제로 확장한 범위

- 1개 사업·공고 1쌍에서 **4개 사업·8개 전체 공고·4개 연도별 쌍**으로 확장했습니다. 같은 서울시 자료의 목적 표집이며 전국 정책이나 독립 대규모 벤치마크가 아닙니다.
- 나이, 출생일 범위, 적용 대상별 소득 상한, 네 종류 기초생활급여 제외 목록을 자동으로 읽습니다. 32개 항목 중 30개는 잠정 기준값, 2개는 제외 조건 미확인입니다. 미확인을 ‘제외 없음’으로 바꾸지 않습니다.
- 전체 문서의 첫 일치, 문자 TF-IDF 상위 1개, 고정 KLUE 평균 임베딩 상위 1개, TF-IDF 상위 3개 일치 확인을 **동일한 파서**로 비교했습니다. 새 모델 학습은 0회입니다.
- 원본 파일과 추출 텍스트의 해시, 페이지/구역 내 문자 위치, 추출 근거 해시를 남겼습니다. 전체 PDF/HWPX·추출 원문은 재배포하지 않습니다.
- 추출값을 536개 고정 가상 조건 입력에 실행했습니다. 이 중 기준값으로 판독 가능한 입력은 486개, 확인 필요 입력은 50개입니다. 동일 조건을 반복한 민감도 분석이며 536개 독립 언어 사례가 아닙니다.
- 이사비의 **자동 급여 제외 목록 + 기존 수동 주거 규칙**을 연결해 이전 14개 사례를 다시 실행했습니다. 주거 산식까지 자동 추출했다고 주장하지 않습니다.

## 자료와 판독 범위

| 사업 / 공고 | 나이 표기 | 출생일 범위 | 소득 기준과 범위 |
|---|---|---|---|
| 이사비 2022-2542 → 2023-1362 | 19–39 유지 | 1982–2003 → 1983–2004년의 명시 범위 | 120% → 150% |
| 월세 2023-1269 → 2024-805 | 19–39 유지 | 1983–2004 → 1984–2005년의 명시 범위 | 150% 유지 |
| 청년수당 2023-1649(2차) → 2024-721 | 19–34 유지 | 1988.6.1.–2004.6.30. → 1989.3.1.–2005.3.31. | 150% 유지 |
| 문화패스 2023-2290(2차) → 2024-840 | 19–22 → 20–23 | **2001.1.1.–2004.12.31. 유지** | 일반 150% → 최초 150% / 2023년 수혜자 120% |

출처 URL·공고 날짜·수집 시각·원본 해시는 [sources.json](sources.json), 전체 잠정 기준값과 위치는 [reference.json](reference.json)에 있습니다. 이 쌍들은 **연도별 사업 공고이지 오기 정정 쌍이 아닙니다.** 나이·출생 범위의 차이는 표면 표기와 명시 범위의 관계입니다. 다른 조건까지 결합한 실제 수혜 집단의 동일성이나 증감을 뜻하지 않습니다. 2023년 문화패스의 상반기 선정자 제외 등 미실행 조건도 있으므로 재수혜자의 전체 자격을 비교하지 않습니다.

## 첫 실행: 한국어 모델을 붙이는 것만으로 개선되지 않았다

| 방법 | 값과 근거 일치 / 30 | 잘못된 값 | 보류 |
|---|---:|---:|---:|
| 전체 문서 첫 일치 | 29 | 1 | 0 |
| 문자 검색 상위 1개 | 23 | 0 | 7 |
| KLUE 평균 임베딩 검색 상위 1개 | 15 | 1 | 14 |
| 문자 검색 상위 3개 일치 확인 | 28 | 0 | 2 |

[비교 그림 PNG](figures/condition-reading.png) · [벡터 PDF](figures/condition-reading.pdf)

네 방법 모두 별도 미확인 2항목은 보류했습니다. 이를 30개 조건의 점수에 더하지 않았습니다. [전체 결과](results/RESULTS.md), [항목별 오류](results/errors.json), [원시 예측과 근거](results/predictions.json), [버전 비교](results/pairs.json), [조건 실행](results/gates.json)을 공개합니다.

**구체적인 실패:** 전체 검색은 2023년 월세 공고에 함께 안내된 정부 사업의 60%를 서울시 사업의 150% 대신 가져왔습니다. KLUE 검색은 2024년 청년수당의 우선선정 85%를 신청 자격 150% 대신 읽었습니다. 문자 상위 3개는 두 소득값의 충돌을 감지해 보류했지만, 그것만으로 역할을 구분하지는 못했습니다. 값이 그럴듯해도 **어느 사업의 자격인지, 우선순위인지**가 다르면 틀린 답입니다.

KLUE-RoBERTa는 한국어 마스크 언어 모델이며 이번 평균 풀링은 검색용으로 학습되지 않은 약한 신경망 기준선입니다. 생성형 LLM, 최신 검색 모델, 충분히 학습한 추출 모델의 한계로 일반화하지 않습니다. 사용하지 않는 pooler의 초기화 경고가 있었으며 추출에는 `last_hidden_state`만 사용합니다.

PDF 배치 순서도 분리했습니다. 동일 문자 검색에서 2024년 월세는 기본 텍스트 순서 2/4, 좌표 정렬 4/4였습니다. 다른 문서는 이 설정에서 값 일치 수가 같았습니다. 원문을 손으로 고친 결과가 아니라 공통 전처리 설정 비교이며 OCR·표 이해를 해결했다는 뜻이 아닙니다.

## 오류를 본 뒤 진행한 두 번의 개선

1. 신청 자격 구역만 읽는 사후 실험: **26/30 일치, 4개 보류**. 다른 사업의 60% 오류는 사라졌지만 ‘지원요건’이라는 제목을 놓쳐 이사비 공고 한 개를 모두 보류했습니다. 새 합성 반례 8개에서는 3개만 맞았습니다.
2. 제목의 다른 표현, 가까운 수혜자 표지, 허용 문장의 극성을 보완: **30/30 일치**, 같은 합성 반례에서는 **6/8**. 구역 안에 다른 사업의 기준이나 우선선정 기준을 넣은 두 반례는 여전히 틀립니다.

두 결과는 [posthoc.json](results/posthoc.json), [refined.json](results/refined.json)에 분리했습니다. **30/30은 이미 읽고 개선에 사용한 8개 공고에 대한 적합 결과**입니다. 6/8도 관측한 반례에 대한 수정 결과입니다. 새 문서 정확도·보류 보장·실용 시스템 성능으로 내세우지 않습니다. [원래 파서](reader.py), 첫 추론과 결과는 그대로 보존했습니다.

기존 실행기 연결에서는 문자 검색과 보완판이 14개 사례 × 2개 버전의 28개 상태를 기존 수동 결과와 일치시켰고, KLUE 기준선은 11개가 일치했습니다. 근거 검색 실패가 실행 단계의 보류로 전파되는 모습입니다. [연결 코드와 140개 방법별 추적](results/bridge.json)은 선택한 주거·급여 조건만 다룹니다.

## 연구 질문이 더 구체해진 지점

**조건은 값 하나가 아니라 `(사업, 역할, 적용 대상, 비교 연산, 값, 근거)`의 묶음이어야 합니다.** 이번 결과에서 실제로 확인한 것은 숫자 검색·고정 창·구역 필터가 이 범위를 놓치는 구체적인 사례입니다. 이 튜플 전체를 일반 문서에서 자동 판독하는 문제는 아직 해결하지 않았습니다.

- 표면 나이가 바뀌어도 명시 출생 범위는 유지될 수 있고, 같은 나이 표기에서도 출생 범위가 이동합니다. 변경 탐지는 먼저 비교할 의미 단위를 정해야 합니다.
- 일반 자격, 우선순위, 다른 사업 안내를 구분한 근거 선택을 조건 실행과 함께 평가할 수 있습니다. 숫자 정확도만으로 잘못된 문맥을 숨기지 않습니다.
- 미언급·추출 실패·근거 충돌은 서로 다른 확인 요청을 만들어야 합니다. 이번 파이프라인은 이유를 기록하지만 질문의 효과나 사람의 검토 시간은 아직 측정하지 않았습니다.
- 실제 정정 공고, 별표만 수정된 문서, 다른 기관의 새 사업을 다음 독립 평가 자료로 잠글 수 있습니다. 현재의 같은 출처 적합과 분리해야 합니다.

이 연구의 지향점은 **한국어 정책 버전의 조건 범위와 실행 결과를 연결하는 평가**입니다. [ConditionalQA](https://aclanthology.org/2022.acl-long.253/), [ContractNLI](https://aclanthology.org/2021.findings-emnlp.164/), [ShARC](https://aclanthology.org/D18-1233/)의 조건부 답변·근거·추가 질문과 연결됩니다. 이 소규모 실험만으로 새로운 학술적 방법의 우수성이나 신규성을 주장하지 않습니다.

## 재현과 검증

Python 3.12.9, PyMuPDF 버전은 `protocol.json`, 나머지는 [requirements.txt](requirements.txt)를 참고합니다. CPU 실행이며 신규 학습·유료 API 호출이 없습니다. 모델은 [공식 KLUE 모델 카드](https://huggingface.co/klue/roberta-base)의 지정 리비전과 가중치 해시를 검증합니다. 준비한 모델 경로를 사용하세요.

```bash
cd research/policy_condition_reading
python3 prepare.py --cache /tmp/policy-condition-sources
python3 infer.py --cache /tmp/policy-condition-sources --model /path/to/klue-snapshot --output /tmp/condition-inference
python3 evaluate.py --predictions /tmp/condition-inference/predictions.json --output /tmp/condition-scores
python3 posthoc.py --cache /tmp/policy-condition-sources --output /tmp/condition-posthoc.json
python3 refined.py --cache /tmp/policy-condition-sources --output /tmp/condition-refined.json
python3 bridge.py
python3 verify.py --cache /tmp/policy-condition-sources
```

`infer.py`는 기준 라벨을 열지 않습니다. TF-IDF는 문서 내 비지도 적합이며 기준값 학습이 아닙니다. 다만 연구자가 자료를 먼저 읽고 파서를 설계했으므로 **이 사실만으로 평가가 블라인드가 되지는 않습니다.** `freeze.json`은 첫 실행 직전 파일 해시이며 사전등록이 아닙니다. 원본이 교체되거나 추출 라이브러리 버전이 달라져 텍스트 해시가 바뀌면 재현을 중단합니다. 2023년 월세 PDF는 MuPDF 구문 경고가 있으나 사용한 조건 구절과 페이지는 확인했습니다.

독립 사람 판독은 **0명**입니다. [빈 검수 양식](human_review_blank.csv)과 [검수 지침](REVIEW_GUIDE.md)은 실제 사람이 채우기 전에는 완료된 평가가 아닙니다. 소득 입력은 이미 별도로 확인한 행정적 백분위 기준값을 가정하며 실제 급여나 건강보험료를 변환하지 않습니다. 현재 제도 안내·전체 자격 판정·법률 검토 완료를 의미하지 않습니다.
