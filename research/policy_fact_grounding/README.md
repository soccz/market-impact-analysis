# 정답 뒤에 가려진 사실 오류를 찾는 한국어 정책 NLP

정책 규칙을 계산한 답이 맞아도, 그 답에 사용한 신청자 사실은 틀릴 수 있다. 앞선 환산식 실험에서 **24,000,240원을 24,002,400원으로 읽고도 같은 상한 초과 답을 내는 사례**를 확인했다. 이번 개인 후속 연구는 답·사실의 공동 정확성, 의미 보존과 의미 변경에 대한 서로 다른 반응, 규칙의 자동 반례를 실제로 검증한다.

기존 개발에서 생긴 문제 → 사실·정정 판독 → 조건별 판단과 저장 판단 갱신 → 규칙·신청자 사실 분리 → **금액 근거를 대조하고, 규칙이 달라지는 사례를 찾기**로 연구를 이어갔다. 공개 모델을 활용한 AI 지원 개인 연구이며 과거 교수님 제출물·서울경제 제공물의 성과로 소급하지 않는다.

## 네 단계를 실제로 실행

| 단계 | 입력·실행 | 해석 범위 |
|---|---|---|
| 이전 실패에서 방법 개발 | 이전 공개 응답에서 보증금·월세 오독을 확인하고 주장만 보는 검증기 구현 | 사후 개발, 이전 데이터 성능은 새 검증이 아님 |
| 표현과 의미의 대조 | 작성 규칙 8개 × 기본·동일 의미·내용 변경·정보 누락 = 32주장, 두 모델 144응답 | 같은 사례의 변형; 32개 독립 사건이 아님 |
| 새 문서 첫 적용 | 방법 고정 후 양산·용인 공식 HWP 2개, 4범위·16가상 주장, 72응답 | 수동 범위·AI 잠정 참조·기관 2곳에 한정 |
| 반례 및 재현 감사 | 이전 36개 추출 규칙과 참조 규칙의 불일치 검색, 20개 반례의 독립 Fraction 재실행 | 제한된 정수 도메인에서 프로그램 차이를 보임 |

새로 저장한 모델 응답은 총 **216개**, 새로 작성한 기본 주장은 **48개**다. 이전 80주장의 재채점과 36규칙 반례 검색에는 추가 언어모델 호출이 없다. 모델 추가 학습 0회, 독립 사람 주석 0명이다. 로컬 동결은 실행 순서를 기록하며 외부 사전등록을 뜻하지 않는다.

## 무엇을 검증·보정하는가

`grounding.py`는 정책·정답을 입력받지 않는다. 신청자 문장에 명시된 본인/가구의 단일 보증금·월세·연소득 위치를 찾아 억·만·쉼표·소수 표기를 정확 유리수로 검산한다. 추출값과 다를 때 (a) 판단 보류 또는 (b) 근거가 명확한 값만 교체하는 두 경로를 같은 저장 응답으로 비교한다. ‘내 보증금은 밝히지 않았다’가 명시되어 있으면 생성된 값을 미확인으로 되돌릴 수 있다.

여러 금액, 정정·범위·근사 표현, 외부 주체만 있는 문장, 지시어, 미지원 숫자 표기는 자동 해결하지 않는다. 검사 범위 밖이라는 사실을 정확 판독으로 세지 않는다. 정책의 상한·연결·예외, 일반적인 주체·공통 지시 관계, 부정·급여 조건은 이 금액 검증기가 고치지 않는다. 발견한 모델 오류에 맞춰 만든 제한적 검증이므로 포괄적인 한국어 수치 이해를 입증하지 않는다.

정책과 신청자 프로필은 [이전 동결 추출 프롬프트](../policy_compositional_reasoning/infer_extended.py)로 각각 읽는다. 두 모델은 Qwen3.5:9b와 공개 Kanana 1.5 8B Q4_K_M이다. 정확한 모델 해시·형식·예시는 [모델 기록](../policy_compositional_reasoning/models.json)에 있다. Qwen의 추론 표시를 끈 조건, 온도 0, seed 20261001, 문맥 8192, 정책 출력 3072·사실 512·직접 판단 256토큰으로 고정했다. 이 연구에서 생성한 코드를 실행하지 않으며 이전 타입 검증과 조건 해석기를 재사용한다.

## 답과 근거를 함께 평가

최종 답, 신청자 사실과 주장 방향 전체 일치, **답+사실 공동 일치**, 검사 포함률, 보류 수, 수정이 복구·훼손한 답과 사실을 각각 기록한다. 미확인 정보 때문에 논리적으로 ‘확정 불가’인 것과 모델 출력 실패·검증 불일치로 ‘보류’한 것은 별개다. 미표기 필드와 null은 같은 미확인으로 취급하며, 공통 필드 전체의 의미가 같아야 사실 일치로 센다.

같은 의미의 표기에는 답이 유지되어야 하고 내용·연결·경계가 바뀌면 해당 결론이 변해야 한다. **두 답 모두 맞는 쌍**을 별도로 세어 같은 오답을 반복하는 일관성을 성공으로 보지 않는다. AND/OR 및 이하/미만 문맥 쌍은 신청자 문장을 고정하고 규정만 바꾼다. 참조 규칙을 제공한 점수는 오류 위치를 찾는 진단이며 실제 방법 성능이 아니다.

## 반례는 무엇을 증명하는가

`counterexamples.py`는 추출 규칙과 AI 잠정 참조 규칙의 XOR를 Z3로 풀고 반대 판단을 내는 가상 사실을 찾는다. 수치는 비음수 정수로 제한한다(나이 ≤120, 주당 시간 ≤168, 소득 비율 ≤1000, 기타 ≤10¹²). 날짜는 2000–2100, 문자열은 두 규칙의 리터럴과 기타 한 값이다. 따라서 반례를 못 찾았다는 말은 그 도메인 밖의 동치성을 보장하지 않는다. 문서와 참조 규칙의 일치도 별도로 검수해야 한다.

20개 반례를 기존 해석기로 재실행한 뒤 `witness_audit.py`의 별도 Python/Fraction 비교로 모두 확인했다. Z3의 비ASCII 문자열 이스케이프를 사람이 읽는 Unicode로 복원하고 도메인 소속도 점검했다. 최초 결과는 `counterexamples.json`, 표시·검수용 정규화는 `counterexamples_audited.json`에 함께 남긴다. 이 감사는 모델 방법을 바꾸지 않는다.

원문 HWP, 전체 추출문, 원시 모델 산문은 배포하지 않는다. 공식 링크·좌표·해시, 작성 가상 주장, 정제된 구조와 점수, 실행 코드만 공개한다. 이용 조건이나 권리 귀속의 법률적 보증은 이 기록의 범위가 아니다.
