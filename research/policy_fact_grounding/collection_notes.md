# 새 문서 선정과 범위 기록

방법 동결(2026-10-01 13:30 UTC) 뒤 공개 기관 자료를 검색했다. 금액·소득과 복합 조건을 포함하는 2문서, 4범위, 16작성 주장이라는 목표를 예측 전에 정했다. 기존 연구의 대전·광주 자료는 새 문서에 포함하지 않았다. 선정은 무작위 표집이 아니다.

안양·제천 후보를 살펴본 뒤 김해·양산, 구미·용인 자료를 확인했다. 김해 다운로드는 HTTP 200이어도 PDF 대신 파일 없음 HTML을 반환하여 파일 시그니처 검사에서 제외했다. 구미 자료는 검색 도구에서 PDF가 보였지만 직접 다운로드가 다른 도메인으로 이동한 뒤 HTTP 500을 반환해 사용하지 않았다. 양산·용인은 공식 게시물에서 연결된 HWP 첨부를 TLS 검증을 유지하여 확보했다. URL·시각·해시는 `sources.json`에 기록했다. 파일명에 `(안)`이 있는 양산 첨부를 확정 최종판이라고 바꾸어 부르지 않는다.

pyhwp의 텍스트 CLI는 표를 `<표>`로 생략했다. 이를 발견한 후 XML의 각 Paragraph가 직접 가진 LineSeg/Text를 읽어 중첩 표를 포함한 비어 있지 않은 문단을 재구성했다. 양산 463문단, 용인 255문단이다. LibreOffice 변환은 두 파일 모두 로드 오류로 실패했으며 원래 인쇄 지면의 시각적 대조는 하지 못했다. 평가 입력은 버전이 고정된 XML 추출 문단이며, 문서 레이아웃 이해 실험이 아니다. 표 안의 용인 환산식은 XML 문단 75에 있고, 계수 12/0.064=187.5를 정확 유리수로 표현했다. 좌표·추출 해시로 같은 입력을 재생성한다.

양산 신청자격 ③(문단 21)은 보증금·월세 두 상한을 함께 요구한다. 제외대상 ⑤(문단 72)는 두 초과 조건을 ‘및’으로 연결한다. 둘을 서로의 정확한 논리적 부정으로 취급할 수 없다. 첫 범위는 신청자격 ③과 월세 없는 전세 제외(22)만 평가하며, 제외대상 ⑤를 임의로 고쳐 합치지 않는다. 나이와 출생연도 등의 다른 조항도 평가 밖이다. 이것은 공고 전체에 대한 수급 자격 판정 자료가 아니다.

두 번째 양산 범위는 이미 산정된 중위소득 비율 (60,150]만 사용하며 보험료 환산은 평가하지 않는다. 용인은 환산보증금 상한과 소득·4종 급여 제외 결합을 각각 평가한다. 면적, 예산, 다른 제외 사항은 명시적으로 범위 밖이다. 모든 신청자 문장은 직접 작성한 가상 사례이며 실제 신청자 자료가 없다. 참조 규칙·사실·라벨은 AI 지원 잠정 주석이고 독립 사람 검수는 0명이다.

`official_freeze.json`은 원문 선택·범위·16주장·참조·추출 코드를 첫 새 문서 예측 전에 고정한 로컬 기록이다. 외부 사전등록은 아니다. 방법·프롬프트는 새 문서 결과를 본 뒤 수정하지 않는다.
