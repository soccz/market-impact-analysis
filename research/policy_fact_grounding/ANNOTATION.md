# 평가 단위와 주석

독립 사람 검수는 **0명**이다. 현재 참조는 AI 지원으로 작성하고 코드로 일관성을 확인한 잠정 기준이다. 규칙 실행과 라벨이 서로 맞는다고 해서 원문 의미가 외부 사람에게 검증된 것은 아니다. `human_review.csv`의 48행은 비어 있는 독립 검수용 양식이다.

작성 통제 32개는 8규칙에 기본·동일 의미 표기·의미 변경·정보 누락을 배치했다. 24개 기본-변형 쌍/모델과 별도 규정 변경 2쌍/모델을 평가한다. 같은 규칙을 공유하는 반복을 독립 문서처럼 세거나 표준 오차·유의성을 주장하지 않는다. 금액 검사 범위 밖인 거주기간·나이·AND/OR도 보존해 방법의 적용 한계를 확인한다.

새 문서는 양산과 용인 각 2범위·8주장이다. `official_reference.json`의 원문은 좌표 객체로 대체했고 `prepare_inputs.py`가 원본 HWP에서 모델 입력을 재생성한다. 양산 (60,150] 소득 조건, 용인 환산보증금 deposit + rent × 12/0.064 ≤ 300,000,000, 생계·의료·주거·교육급여 제외 결합을 선택했다. `collection_notes.md`에 공고 내부 표현 차이와 표 추출의 한계를 보존했다. 건강보험료 환산, 전용면적, 예산·심사순위 등 범위 밖 조건이 모두 충족되었다고 가정하지 않으며 결과는 해당 범위만 판정한다.

모든 가상 주장은 해당 범위의 요건 충족 여부를 주장한다. supported는 문서 조건과 알려진 사실로 그 주장이 성립함, contradicted는 그 부정이 성립함, not_established는 두 가능성이 남음을 뜻한다. abstain은 추출·형식·검증 문제로 판독을 보류한 시스템 상태다. 부정형 주장에서는 충족 여부와 주장 진위가 반대일 수 있다.

사람 검수 시 모델 예측·수정값을 가리고 원문 및 범위, 주장만 먼저 제시해야 한다. 별도 판독자별 라벨·사실·근거·범위 불확실성을 기록하고 의견이 갈리면 조정 기록을 남긴다. 현재 빈 양식을 완료된 사람 검수로 세지 않는다. 원문 해석에 이견이 생기면 기존 결과를 덮어쓰지 않고 버전과 변경 이유를 기록한다.
