# 잠정 주석과 공개 범위

104개 주장은 연구용으로 작성한 가상 신청자 설명이다. 실제 개인의 자료가 아니다. 참조 규칙·사실·라벨은 AI 지원 잠정 주석이며 독립 사람 검수 0명이다. 모델의 출력과 맞도록 참조값을 사후 수정하지 않았다. `human_review.csv`는 104행 모두 검토란이 비어 있다.

- 긍정 주장: 알려진 사실을 고정했을 때 모든 가능한 경우가 요건을 통과하면 지지, 모두 통과하지 못하면 반박, 둘 다 가능하면 확정 불가다. 부정 주장은 지지와 반박을 뒤집는다.
- 신청자 사실이 없다는 것과 정책 조항 자체가 불충분한 것은 다르다. 누락 값을 0·거짓·비수급으로 채우지 않는다. 원문에 없는 부모→본인, 신청일→가입일 전환을 허용하지 않는다.
- 범위 밖 요건을 가져와 전체 수급 자격을 판정하지 않는다. 근로시간·외국 국적·급여 등 선택한 범위의 판독이다.
- 기준 구조를 표현할 수 없는 모델도 의미상 정답을 확정 불가로 바꾸어 구제하지 않는다. 형식·자료형 실패는 `abstain`, 근거·사실 부족은 `not_established`로 분리한다.
- 정책 동등성은 잠정 기준 구조와 제한된 필드 도메인 안의 비교다. 전체 자연어 의미의 동등성이나 실제 법적 자격을 증명하지 않는다.

## 원문 확인과 선택

[source_spans.json](source_spans.json)의 단위·시작·끝·해시는 [sources.json](sources.json)의 고정 추출기에 대한 좌표다. PDF는 0부터 시작하는 페이지, HWPX는 표 내부 중복을 제거한 비어 있지 않은 문단 순서다. [prepare_inputs.py](prepare_inputs.py)로 재생성한다. 전체 원문을 검토한 뒤 범위를 선택했으며 자동 검색 평가가 아니다.

대전 공식 운영 도메인 PDF는 인증서 만료로 TLS 검증이 꺼진 상태에서 받았다. 웹에서 읽힌 같은 URL의 공고번호·본문 및 PDF 화면을 대조하고, 8쪽 추출과 바이트 재다운로드를 확인했다. 이 과정은 전송 경로의 암호학적 인증을 대체하지 않는다. PyMuPDF가 사전 구조 경고를 출력했으나 고정된 8쪽 텍스트와 위치 해시는 재현되었다.

광주 공고는 공개 배포처 열고닫기의 시 명의 HWPX 사본이다. 공식 사이트는 여러 경로에서 HTTP 400을 반환하여 공식 원본의 동일성은 확인하지 못했다. XML에서 298문단을 읽었으며 사용 가능한 LibreOffice는 해당 HWPX 렌더링을 지원하지 않아 원래 지면의 화면 대조는 하지 못했다. 추출·배포처 파일의 동일성과 시 명의라는 점을 원본 인증으로 확대하지 않는다.

대전의 연령 표기와 출생일 범위는 단순한 만 나이 조건으로 합치지 않고 1차 연령 평가에서 제외했다. 광주의 건강보험 소득 판단은 2025 공고가 참조하는 2024 기준을 유지했다. 1차 학력 범위는 일반 학교의 졸업·중퇴·수료·재학·휴학으로 한정했다. 원격대학·학점은행제·졸업예정자 예외와 임대료 환산은 별도 16주장에서 확장했다.

## 독립 검토 절차

검토자는 모델 예측을 보지 않고 출처와 선택 범위, 작성 주장만으로 지지·반박·확정 불가 및 근거 위치를 기록한다. 두 명 이상이 별도로 판독한 뒤 불일치를 중재하고 버전별 참조값과 점수를 보존해야 한다. 현재 이 절차는 수행 전이며 양식·필드만 제공한다. CSV에는 reviewer_id, decision, evidence, uncertainty, adjudication을 비워 두었다.

공개물은 직접 작성한 주장, 제한된 조건 구조, 원문 위치·해시, 정제된 모델 출력, 집계와 그림이다. 문서 전문, 모델의 자유서술 원문, 기존 고객 납품물, 개인정보, 로컬 비공개 경로를 포함하지 않는다. 공개 제한이 모든 권리 문제에 대한 법률적 보증을 뜻하지 않는다.
