# 독립 판독을 위한 준비 기록

완료된 사람 검수는 **0명**입니다. [28행 양식](human_review_blank.csv)은 비어 있습니다. AI가 구현한 결과를 사람의 정답으로 재명명하지 않습니다.

판독 단위는 `case_id × version`입니다. 한 버전의 주거 조건과 지정 복지급여 제외 조건만 판독합니다. 결과값은 `pass / fail / unknown`, 근거 위치는 공고의 장·항목 또는 PDF 쪽수로 기록합니다. `pass`는 실제 지원 자격이나 지원금 수령을 뜻하지 않습니다.

1. 향후 독립 평가에서는 판독자에게 원본 공고와 `cases.json`의 **id·profile만** 제공하고 구현 결과·설명 note는 제공하지 않습니다. 현재 공개된 결과를 이미 봤다면 그 사실을 기록하며 블라인드 평가로 세지 않습니다.
2. 원문 표, 각주, 예외, 별도 제외 목록을 함께 읽습니다. 지원 상한이 같다는 사실로 조건 불변을 추론하지 않습니다.
3. `benefits: []`는 지정 급여 비수급, `null`은 미확인입니다. 여러 급여를 받는 경우 어느 하나라도 명시된 제외에 해당하는지 확인합니다. 입력의 미확인을 실제 비수급으로 바꾸지 않습니다.
4. 2022년 환산 문구의 단위 해석을 독립적으로 적습니다. 구현의 두 후보를 정답 선택지로 강제하지 않습니다. 표를 우선하는 판독, 다른 문구 해석, 기관 확인 필요 등 이견을 그대로 기록합니다.
5. 각자 판독을 먼저 확정한 다음에 불일치를 비교합니다. 합의 전 원본 라벨은 보존하고 변경 이유를 기록합니다.

후속 사건은 문서 쌍 단위로 나눠야 합니다. 이 사례의 경계값·표현을 바꾼 자료를 독립 정책 사례로 세지 않습니다. 자동 추출을 붙인 다음에는 다음 오류를 분리합니다.

| 층위 | 확인할 오류 |
|---|---|
| 문서 연결 | 다른 정책·다른 연도의 문서를 잘못 연결했는가 |
| 조건 추출 | 대상, AND/OR, 예외, 제외, 수치 단위와 범위를 누락했는가 |
| 근거 | 실제 구절이 조건을 지지하는가; 요약의 미언급을 삭제로 읽었는가 |
| 실행 | 경계 포함, 금액 연산, 미확인 입력을 잘못 처리했는가 |
| 변경 설명 | 결론을 바꾸는 조건을 놓치거나 관계없는 조건을 원인으로 제시했는가 |
| 보류 | 근거 부족과 실제 미충족을 혼동했는가; 명시적 제외에도 불필요하게 보류했는가 |

두 조건 묶음에 대한 최소 변경 집합은 실행상의 정의입니다. 자연어 설명의 질이나 사람의 검토 시간은 별도 평가해야 합니다.
