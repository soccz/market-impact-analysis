# 실제 정정·수정 공고의 버전, 표 구조, 가능성 표현

2026-10-01 · soccz 개인 후속 연구 · AI 지원 구현·판독 · 독립 사람 검수 0명

기존 연구가 새 공고에서 대상·예외를 놓친 뒤, **‘정정 공고’라는 문서의 이름과 특정 대상의 내용 변화는 어떻게 구분하는가**를 실제 자료로 조사했습니다. 옥천군장학회 자료 두 계열에서 **명시적 오기 정정 1쌍과 수정 공고 1쌍**을 확보했습니다. 원문을 본 뒤 설계한 탐색이며, 사전등록·독립 평가·학습 모델 성능으로 해석하지 않습니다.

## 결과부터 읽기

- **버전 확인:** 2024년 최초 게시물과 정정 게시물에서 현재 내려받은 HWP는 바이트까지 같습니다. 이 둘만 과거·현재로 사용하면 표의 변화 14개를 모두 놓칩니다. 대학이 보관한 이전 내용의 공고를 확보하고, 발행기관이 명시한 ‘기존’ 표의 18개 값과 모두 대조했습니다.
- **대상 연결:** 대회 범위 × 개인·단체 규모 × 순위의 18개 질문에서 표 금액은 14개가 달라지고 4개는 같습니다. 병합된 머리글 경로와 단위를 함께 읽어 18개 전후 값을 복원했습니다. 18개 독립 정책 사건이나 새 문서 정확도 100%를 뜻하지 않습니다.
- **가능성 보존:** 2025년 수정 공고는 다른 장학금 신청 예정자의 유의 문장에 구체적 예시를 추가했습니다. 전후 모두 ‘제외대상이 될 수 있으므로’ 확인하라는 표현입니다. 해당 구절만으로 새로운 확정적 제외를 도출하지 않습니다.

## 원문을 확보한 과정

|---|---|---|
| 2024 하반기 특기장학생 금액표 | [충북도립대학교가 2024-09-10 게시한 공고 첨부](https://www.cpu.ac.kr/home/sub.do?menukey=427&mode=view&no=1004355566&page=1), 문서번호 2024-1224 | [옥천군장학회 2024-09-20 정정 게시물](https://ocjh.oc.go.kr/Content.php?basecode=124&mod=view&no=7981&table_id=public)의 기존·정정 표 및 전체 공고 첨부 |
| 2025 다자녀 장학생 유의 문구 | [2025-339, 2025-02-26 최초 공고](https://ocjh.oc.go.kr/Content.php?basecode=124&mod=view&no=8502&table_id=public) | [2025-370, 2025-03-04 수정 게시물](https://ocjh.oc.go.kr/Content.php?basecode=124&mod=view&no=8521&table_id=public)의 변경표·전체 본문 |

추가로 [2024-09-09 최초 게시물](https://ocjh.oc.go.kr/Content.php?basecode=124&mod=view&no=7901&table_id=public)의 현재 HWP·PDF를 확인했습니다. HWP는 정정 게시물 첨부와 SHA-256이 같고, PDF 8쪽도 정정 금액입니다. **이 관측만으로 서버가 언제 파일을 교체했는지는 알 수 없습니다.** 대학 사본의 이전 표는 발행기관이 직접 제시한 기존 표와 18/18 값이 일치하고, 현재 전체 공고의 표는 정정 표와 18/18 일치합니다. 두 문서 전체의 의미가 그 표만으로 동일하다고 주장하지 않습니다.

게시일, 문서 내부 날짜, 수집 시각을 [sources.json](sources.json)에 따로 기록했습니다. 2024년 정정 안내의 내부 날짜는 09-19, 게시일은 09-20입니다. 2025년 수정 공고는 03-04에 게시됐지만 내부 날짜는 02-26을 유지합니다. 이를 효력 발생일이나 파일 생성일로 바꾸어 읽지 않습니다.

총 7개 원본 파일의 해시를 고정했습니다. 전체 원문과 변환본은 공개 저장소에 넣지 않습니다. [수집 기록](collection_log.json)에는 원본 두 버전을 확보하지 못한 완도군 후보도 제외로 남겼습니다. 인터넷 전체나 모든 정정 공고를 전수 수집했다는 뜻은 아닙니다. 확보한 두 계열의 전체 문서와 선택한 표의 18개 조합을 확인한 것입니다.

## 금액은 숫자만으로 누구의 값인지 알 수 없다

2024년 표는 전국·국제 대회 아래 개인과 단체가, 단체 아래 2–4명과 5명 이상이 놓인 병합 구조입니다. `hwp5txt`의 평문 추출은 표를 자리표시자로 생략하므로 입력으로 사용하지 않았습니다. `hwp5proc xml`에서 셀 좌표·병합 범위를 읽고, **대회 → 개인/단체 규모 → 순위 → 금액**을 연결했습니다. 머리글이 없거나 질문의 대상이 불완전하거나 단위가 없으면 답하지 않습니다.

금액 단위는 전체 HWP의 표 근처 ‘천원’에서 확인했습니다. 정정 안내 HTML 표 자체에는 단위가 없어 이 표만으로는 금액 단위를 확정하지 않습니다. HTML의 원시 숫자와 전체 HWP의 값을 교차 확인하고, 금액 출력에는 전체 공고의 단위 근거를 연결합니다.

| 방법 | 전후 금액 모두 일치 / 18 | 변화 여부 일치 / 18 | 거짓 변화 | 놓친 변화 |
|---|---:|---:|---:|---:|
| 첫 숫자만 선택 | 2 | 14 | 4 | 0 |
| 순위만 맞추고 첫 숫자 선택 | 3 | 14 | 4 | 0 |
| 병합 머리글·순위·단위 연결 | 18 | 18 | 0 | 0 |
| 현재의 두 첨부를 과거·현재로 취급 | 4 | 4 | 0 | 14 |

‘정정이면 모든 질문이 변경’이라는 규칙도 14/18로 보이지만 유지된 4개를 틀립니다. **변화 여부 점수만 보면 잘못된 전후 금액을 놓칠 수 있어 두 측정을 함께 남겼습니다.** 모든 비교는 이미 관측한 동일 표에 대한 구조 복원 진단입니다. 오기 정정을 새로운 정책 증액으로 부르거나 실제 지급액·소급 권리를 추정하지 않습니다. 단체 금액의 개인별 배분과 전체 자격은 연구 범위 밖입니다.

## 추가된 문장이 곧 새로운 확정 조건인가

2025년 수정은 타 기관 장학금 신청 예정자 유의 문구에 댐 주변 지역 학생 장학금이라는 예시를 추가합니다. 전후 모두 가능성과 확인 요구를 유지합니다. 구현은 선택한 구절에서 `needs_confirmation`을 반환하고 `definite_exclusion=false`를 보존합니다. 텍스트 변화는 확인되지만, 이 근거만으로 적용 자격의 확정적 변화는 성립하지 않는다는 출력입니다. 전체 정책이 동일하다는 주장도 아닙니다.

이 판독은 해당 구절과 짧은 경계 예문의 어휘 규칙입니다. 임의 문장의 부정·인용·중첩 예외를 처리하는 한국어 모델을 개발했다는 뜻은 아닙니다. 신규 모델 학습은 0회입니다. 수정본은 전후 비교표에 같은 구절이 먼저 등장하므로 근거 위치는 뒤에 나오는 실제 본문의 해당 구절로 연결했습니다.

## 재현과 검증

Python 3.12.9에서 아래 버전을 사용했습니다. 원문은 [sources.json](sources.json)의 `url`에서 각 `cache_file` 이름으로 별도 폴더에 확보해야 합니다. 원본이 바뀌면 해시 검증이 중단됩니다. HTML 페이지도 변할 수 있으므로 당시 파일을 확보할 수 없으면 완전한 원문 재현은 불가능합니다. 해시가 다른 최신 파일을 과거 버전으로 덮어쓰지 마세요.

```bash
python -m pip install -r research/policy_revision_audit/requirements.txt
python research/policy_revision_audit/run.py --cache /path/to/source-cache
python research/policy_revision_audit/verify.py --cache /path/to/source-cache
python research/policy_revision_audit/plot.py
```

`hwp5proc`가 PATH에 있어야 합니다. `verify.py`는 7개 행동 테스트, 원본 7개 해시, 표·머리글 근거 위치 270개, 단위·구절·변경 위치 해시, 결과 5개의 바이트 단위 재생성과 기존 연구 산출물 698개의 불변 여부를 확인합니다. PDF 8쪽과 HWP에서 변환한 이전 금액표·수정 비교표의 화면도 별도로 확인했습니다. 자동 테스트가 독립 사람 판독을 대신하지 않습니다.

[source_lock.json](source_lock.json)은 확보 후 자료·잠정 기준·프로토콜 잠금이며, [research_record.json](research_record.json)은 최종 산출물의 해시입니다. 외부 사전등록이 아닙니다. AI 지원 잠정 기준과 평가 구현이 같은 작업 과정에서 작성됐으므로 독립 정답으로 과장하지 않습니다.

## 다음 연구를 어떻게 바꾸는가

학습·평가 단위를 문장 두 개에서 **원본 버전 → 대상 경로 → 명제 → 가능성·확정성 → 적용 결론**으로 확장할 필요가 있습니다. 버전 미확보, 대상 미연결, 언어적 불확실성은 서로 다른 보류 원인이어야 합니다. 이번에 구현한 것은 첫 실제 사례의 버전 검증·표 연결·가능성 보존입니다.

다음 실험은 새로운 기관의 잠긴 정정 쌍에서 (1) 표 머리글 연결, (2) 본문과 별표 버전 참조, (3) 가능·예정·확정·부정의 범위를 강한 문맥 모델과 비교하는 것입니다. 특히 숫자는 같고 대상만 바뀌는 사례, 문구는 늘었지만 확정 결론은 늘지 않는 사례를 분리해야 합니다. 이 계획은 아직 실행 결과가 아닙니다.

[독립 검토 안내](HUMAN_REVIEW.md)와 [빈 판독 양식](human_review_blank.csv)을 남겼습니다. 실제 검토자가 참여하기 전에는 빈칸을 AI 답으로 채워 사람 검수가 완료됐다고 표시하지 않습니다.
