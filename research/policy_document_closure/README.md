# 문서 문맥·중첩 예외·참조 판독: 마지막 고정 실험

이번 개인 후속 연구 묶음의 마지막 실험입니다. 필요한 근거를 검색하는 일, 정책을 실행 가능한 구조로 읽는 일, 같은 사실의 답을 내는 일을 분리해 확인했습니다. **조건 구조화가 직접 판독보다 좋다는 결론은 얻지 못했습니다.** 직접 판독은 Qwen 33/48·공개 Kanana 27/48, 전체 본문 → 그래프는 0/48·0/48이며 판독 보류는 48개·48개입니다.

이전 [원문 정합성 실험](../policy_source_alignment/)에서 제한 규칙 비교군도 최종 점수가 같았던 한계를 출발점으로 삼았습니다. 이번에는 숫자 정확도만 늘리지 않고, 예외의 적용 범위와 주체가 달라지는 문서 대조를 만들고 새 공식 안내 본문을 수집했습니다. 실패를 확인한 뒤 점수가 오를 때까지 문구를 바꾸지 않았습니다. Kanana CPU 실행의 600초 제한으로 저장하지 못한 요청 1개는 별도 GPU 환경에서 같은 요청으로 재개했습니다. 이 전송 재시도와 모델 로딩만 한 요청은 저장 응답 수에 더하지 않았으며 [실행 사고 기록](runtime_incident.json)에 보존했습니다.

- 작성 문서 4개: 장애/돌봄 예외의 **또는 ↔ 그리고**, 소득 조건의 **본인 ↔ 배우자**. 각 대조쌍은 다른 부분과 신청자 사실을 유지합니다.
- 새 공식 HTML 본문 2개: [고용24 발급 안내](https://www.work24.go.kr/hr/h/a/1100/selectIssuGudn.do), [국세청 신청자격](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7783&mi=2452). 방법 고정 후 수집했습니다.
- 문서당 작성 사례 8개, 총 48개. 모든 방식에 같은 구조화 사실을 제공했습니다. 자연어 사실 추출의 추가 성능을 평가한 것은 아닙니다.
- 새 저장 응답 120개, 두 모델 각 60개. 추가 학습 0회, 독립 사람 판독 0명. 평가 전 로컬 동결 2개, 예측 이후 성능 목적 수정·재시도 0회.

## 무엇을 분리했나

`method.py`는 조건의 모두/하나라도/부정/참조를 중첩한 그래프를 검증하고 실행합니다. 관련 정보가 비어 있을 때 가능한 값별 결론을 비교하며 같은 미확인 사실을 서로 독립인 값으로 풀지 않습니다. 순환·출처 ID 오류·지원하지 않는 형식을 거부합니다. 구조 검증이 원문 해석의 정확성을 증명하지는 않습니다.

검색은 범위 질의와 문단의 문자 bigram 중첩 상위 4개에서 시작하고, 명시된 조/별표 참조를 확장합니다. 신청자 사실과 참조 답은 검색·정책 추출에 들어가지 않습니다. 전체 본문 직접 판독과 전체 본문 그래프 추출은 같은 본문·필드·판정 범위를 받고, 후자는 정책을 한 번 추출해 여덟 사례에 재사용합니다.

단순 규칙은 명시된 필드명·수치 조건을 모두 연결하는 약한 비교군입니다. 보수 규칙은 예외·선택·참조 표현을 만나면 보류합니다. 이 둘을 대표적인 한국어 규칙 시스템으로 부르지 않습니다. 모델의 우월성을 입증하기 위해 강한 비교군을 이겼다고 주장할 수 없습니다.

## 사용 범위

공식 페이지의 `#contents` 본문 전체를 입력했지만 질문 범위·필드는 사람이 지정했습니다. 고용24에서는 대규모 기업 근로자와 생계급여 수급 관련 두 제외, 국세청에서는 국적 예외·다른 거주자의 부양자녀·전문직 관련 세 제외를 함께 읽었습니다. 연결된 모든 법령과 첨부자료, 전체 사업의 자격을 판정하지 않습니다.

작성 문서는 설계자가 만든 도전 과제입니다. 실제 언어 분포에서 독립 추출한 문서가 아니고, 공식 자료도 두 페이지뿐입니다. 문서별 수치를 공개하며 48개를 48개 독립 정책 사건으로 세지 않습니다. 참조는 AI 보조 잠정 해석이며 독립 사람 검수는 아직 없습니다. 이번 프롬프트·스키마의 실패를 구조화 추론 일반의 불가능성으로 확대하지 않습니다.

공식 원문 전체·원시 응답·고객 비공개 자료를 공개하지 않습니다. 공개 자료에는 직접 작성한 사례, 구조화된 판정, 출처와 해시, 코드와 실패 결과를 남겼습니다. 이번 실험 묶음의 실행과 공개는 여기서 마감합니다.
