# 독립 판독 준비와 현재 상태

독립 사람 판독은 **0명·0건**입니다. [human_review.csv](human_review.csv)의 48행은 모두 미작성입니다. 이 파일의 준비를 주석 완료로 세지 않습니다. 기대 답과 참조 그래프는 AI 보조 잠정 참조이며, 독립 계산식은 그래프 계산만 검사합니다.

사람 평가를 진행할 때는 서로의 판독과 모델 답을 보지 않는 최소 두 판독자에게 원문 본문·판정 범위·구조화 사실만 제공합니다. `reference.json`의 `label`과 `reference_program`, 모든 `results/` 파일은 판독 입력에서 제외합니다. 공식 페이지의 원문은 출처에서 확인하고 수집 해시와 비교합니다.

판독자는 `eligible`(범위 내 충족), `ineligible`(범위 내 미충족), `undetermined`(관련 사실이 미확인이어서 결론이 달라짐) 중 하나를 선택하고, 근거 문단과 해석상 불확실성을 기록합니다. 문서 자체가 부족하거나 범위가 부적절하면 별도로 표시합니다. 모델의 `abstain`은 추출 실패로 생긴 출력 상태이며 정답 라벨과 구분합니다.

원래 판독을 보존한 뒤 불일치를 조정합니다. 일치도·유형별 불일치·최종 조정 여부를 문서 단위로 보고하고 같은 문서의 여덟 사례를 여덟 독립 정책 사건으로 세지 않습니다. 실제 검토 시간 절감은 별도의 순서 균형 실험과 시간 측정이 필요하며 이번 실행에서 측정하지 않았습니다.

독립 사람이 참여하지 않은 상태에서 AI 응답을 검수자 이름으로 채우거나, 빈 양식을 검수 완료로 표시하지 않습니다. 이번 연구 묶음의 공개 완료와 외부 사람이 필요한 검증을 구분해 마감합니다.

검수자가 실제로 사용할 수 있도록 정답과 모델 출력을 제외한 HTML·JSON·빈 CSV 묶음도 생성했습니다. 두 판독자용 순서는 다르지만 같은 48개 사례이며, 독립 표본 96개로 세지 않습니다. 원문 전체가 들어가는 묶음은 로컬에만 보관합니다.

```bash
python research/policy_document_closure/prepare_review.py --sources /path/to/local-sources --out /tmp/policy-blind-review
```
