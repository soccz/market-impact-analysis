# 주석·표본·오류의 의미

이번 묶음은 개발에 재사용한 48개 주장, 새 기관 첫 적용 20개, 연령 확장 후 새 기관 확인 10개, 기존 전후 문서에 작성한 자연어 주장 18개를 포함합니다. 서로 다른 주장 ID는 96개입니다. 새로 작성한 주장은 48개이며, 변형·경계값·같은 조항의 반복을 독립 정책 사건으로 세지 않습니다.

참조 규칙과 사실·판정은 AI 지원 잠정 주석입니다. 독립 사람 검수는 0명입니다. [human_review.csv](human_review.csv)는 검수를 위한 빈 양식이며 완료 증거가 아닙니다. 판독자는 먼저 각 공식 원문과 범위를 확인하고, 부정·주체·조건 연결·경계·누락 사실·판정 근거·불확실성을 기록해야 합니다. 불일치는 별도 판독과 합의가 필요합니다. 공개 참조를 보지 않는 검수가 가능하도록 양식에 참조 정답을 넣지 않았습니다.

`supported`는 선택한 범위에서 주장을 지지, `contradicted`는 반박, `not_established`는 주어진 사실만으로 확정 불가입니다. 파서가 조건을 표현하지 못하는 경우는 별도 `abstain`이며 참조가 `not_established`인 경우에도 정답으로 세지 않습니다. 전체 사업의 지급·신청 자격 판단은 평가하지 않습니다.

창원·수원은 공식 HTML 안내의 금액 또는 연령 조항만 수작업으로 선택했습니다. 창원 19세 이상~39세 이하, 수원 19세~39세의 양 끝을 포함하는 것으로 주석했습니다. 국민연금공단은 기초연금 지급대상의 연령 하한과 일반 국민연금 가입대상의 연령 구간만 선택했습니다. 직업·국적·재산·소득·보험 유형의 예외는 평가 밖입니다. 해당 사업의 실제 신청 가능 여부를 이 결과로 판단하면 안 됩니다.

개발 자료의 용인 급여 제외 방향은 원문만 아니라 수작업 scope 설명에도 의존하며 후보의 `origin=scope`로 표시합니다. 원문 후보 생성은 정규식 기반 제한 문법입니다. 원문 위치 일치는 문장 의미에 관한 독립 판독이 아닙니다. 특정 규칙을 미리 주거나 원문을 유리하게 정규화한 효과를 모델의 학습 성능으로 세지 않습니다.

서울 전후 공고의 `2025.3.31 이후`는 기존 연구와 동일하게 당일 포함으로 주석했습니다. 주장 금액은 실제 지급액이 아니라 **정확한 지원 상한**입니다. 따라서 상한 30만원 규정에서 “상한 20만원”은 반박입니다. 새 공고의 조건 날짜를 모르면 30만원 또는 40만원 주장은 확정 불가입니다. 저장 답의 오류는 기존 참조를 모델에 제시해서 정정하지 않고, 원문에서 만든 전후 규칙과 작성 주장으로 재계산해 찾습니다.

9개 로컬 동결 파일은 어떤 구현·참조를 언제 고정했는지 보여주는 기록입니다. 외부 사전등록이나 제3자의 타임스탬프 인증이 아닙니다. 연령 보완은 창원·수원 실패 관측 후이며, 그 재평가를 독립 성능으로 발표하지 않습니다. 초기 `evaluate_alignment.py`에는 요청 함수 주입 훅 결함이 보존되어 있습니다. 실행 진입점은 이를 고친 `evaluate_v2.py` 또는 각 전용 report 파일입니다. 채점 함수와 참조를 바꾸지 않았습니다.
