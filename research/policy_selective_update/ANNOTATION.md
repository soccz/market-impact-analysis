# 독립 판독 지침

사람 판독은 아직 수행하지 않았다. `human_review.tsv`의 빈 열은 미완료를 뜻한다. 작성자가 아닌 검토자가 출처를 확보해 원문과 모델 출력의 관계를 따로 평가해야 한다.

1. `sources.json`의 공고 번호·본문 날짜·첨부 해시를 확인한다. 게시 날짜를 인쇄 날짜로 대신 쓰지 않는다. 서울 두 문서는 연도가 다른 공고다.
2. 주장에 명시한 조건만 읽는다. 한도, 신청 종료일, 근무지 등 일부 조건의 충족을 최종 선발이나 실제 지급으로 바꾸지 않는다. 기존 제주는 이전 규칙 투영 규약의 모호성을 별도로 기록한다.
3. 명시적으로 지지하면 S, 반박하면 C, 필요한 정보가 없으면 U를 쓴다. 문서에 없다는 이유로 허용이나 금지를 만들어내지 않는다.
4. 전후 결론과 재검토 경로를 각각 판독한다. 수정된 지역 집합은 같은 조건을 재검토하는 보수적 규약을 사용한다. 명시된 가입일 이전 집단에 한도가 유지되는 것은 해당 금액의 keep 사례다. 이 규약에 이견이 있으면 경로와 답을 각각 기록한다.
5. 근거 위치를 확인한다. 겹치는 검색 창은 합쳐서 구간을 덮을 수 있다. 원문의 일부만 있어도 답을 추론할 수 있는지와, 사전에 지정한 전체 구간을 포함했는지는 서로 다른 기록이다. U의 문맥 근거가 문서 전체의 부재를 증명하지는 않는다.
6. 가능하면 서로 독립적인 두 명 이상이 모델 결과를 보지 않고 판독한 뒤, 차이를 조정한다. 검토자 수·일치율·수정 전후 점수를 공개해야 한다. 현재 양식의 공란을 AI 재판독으로 채우지 않는다.

2025 서울 1쪽의 ‘기존 1개월 → 3개월’ 요약은 이 실험의 2024년 말 본문과 직접적인 변화 쌍이 아니다. 두 확보 문서의 실제 본문은 모두 3개월이다. 문서의 내부 변경 요약을 비교 중인 버전 차이로 곧바로 옮기지 않는다.
